# Pastel UI v0.1.0-beta.12

## Italiano

- **Pastel Weather:** nuova card che legge l'entità meteo scelta, mostra temperatura, umidità e vento disponibili, e riceve le previsioni giornaliere da Home Assistant. Le giornate si possono toccare per vedere il dettaglio.
- **Pastel TV:** nuova card per un `media_player`, con accensione, riproduzione, volume e sorgente secondo le funzioni realmente supportate. I valori si aggiornano dallo stato del dispositivo.
- Entrambe hanno un editor visivo con ricerca filtrata delle entità, nome e colori personalizzabili.
- Le card pubbliche sono 19. La card Albero di Natale è ancora in fase di scelta grafica e non è inclusa in questa versione.

## English

Adds **Pastel Weather** and **Pastel TV** with mobile-friendly Pastel layouts, visual configuration editors, actual Home Assistant state and capability-aware controls. Weather uses the daily forecast subscription. TV only enables services supported by the selected media player. The Christmas tree design is pending approval.
